Cómo funciona

El slider envía el valor PWM (0–255) a tu API Express en POST /api/datos con el campo luz1. Node-RED, que ya tiene el flujo MQTT activo, publica automáticamente el valor en el tópico iot/planta/control al recibir el dato del sensor, y el ESP8266 aplica el PWM al LED. El slider del dashboard de Node-RED también sigue funcionando de forma independiente.
